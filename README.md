# Pension-Calculator

महाराष्ट्र राज्य शासकीय अधिकारी/कर्मचारी यांच्यासाठी प्राथमिक निवृत्तीवेतन गणना वेब-अॅप.

## Files
- `index.html` — मुख्य UI
- `style.css` — डिझाइन / मोबाइल responsive layout
- `script.js` — गणना, Local Storage, Print/PDF

## GitHub वर वापरणे
1. Repository उघडा.
2. `Add file` → `Upload files`.
3. वरील तीन files निवडा.
4. `Commit changes` करा.
5. GitHub Pages मध्ये `Settings` → `Pages` → Deploy from branch → `main` → `/ (root)` → Save.
6. काही वेळाने मिळालेला Pages URL उघडा.

## महत्त्वाची सूचना
हे प्राथमिक/अंदाजे calculation tool आहे. अंतिम सरकारी प्रकरणासाठी लागू महाराष्ट्र नागरी सेवा (निवृत्तीवेतन) नियम, 1982, अंशराशीकरण नियम, 1984, शासन निर्णय, वित्त विभागाचे अद्ययावत आदेश व सक्षम प्राधिकाऱ्याची पडताळणी आवश्यक आहे.

## अधिकृत संदर्भ
महाराष्ट्र वित्त विभाग:
- महाराष्ट्र नागरी सेवा (निवृत्तीवेतन) नियम, 1982
- महाराष्ट्र नागरी सेवा (निवृत्तिवेतनाचे अंशराशीकरण) नियम, 1984

कॅल्क्युलेटरमध्ये गुणक editable ठेवला आहे कारण अंशराशीकरणासाठी लागू वय/तक्त्याची अधिकृत पडताळणी आवश्यक आहे.
